User guide

LocalOpsConsole is a free, open-source (MIT) local Windows diagnostic platform: a PowerShell HTTP engine plus an offline single-page dashboard. Use it to inspect the OS, run safe diagnostics, and apply remediations when elevated.

Source on GitHub · Download

What you get

  • Sidebar of discovered modules (System, Configuration, Graphics, Remote, SyncMe, Printers, Tools, …)
  • Readable result tables and cards (not raw JSON dumps)
  • Sticky live console streaming every command result
  • Header telemetry (CPU, RAM, disk, network, GPU, battery) from the background task runner
  • System live monitor cards plus Configuration (documented Explorer settings)
  • In-app update check against your hosted update.json

Diagnostics vs actions

Diagnostics are read-only or safe probes (status, ping, event errors). Actions change the system (flush DNS, restart spooler, SFC/DISM). Actions often require Administrator rights and ask for confirmation in the UI.

Tip: Start with Getting started, then skim Modules for System telemetry, Configuration, Graphics, Remote, SyncMe, and repair workflows.

Profiles & tiers

Use the profile selector in the app header to control which modules are shown in the sidebar. This is UI-only: backend capabilities are unchanged, and admin-required actions still require elevation.

Modules can be tagged with a numeric tier (1–10). Higher tiers generally mean deeper, engineer-level workflows.

The consolidated Internet Health module (Networking) covers gateway/DNS/public checks, hosts/WINS, VPN, repairs, and an automatic diagnosis engine. Summary loads in a couple of seconds; full diagnosis and speed tests are opt-in.

Safety

  • The listener binds to localhost only.
  • Admin-required actions fail clearly when not elevated.
  • Remote registry access from this console is read-only.
  • Windows Update and SoftwareDistribution resets are destructive by design — read the warnings first.
