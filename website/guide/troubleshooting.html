Troubleshooting

Port already in use

Change port in settings.json (default 8787) and relaunch. Another app may already own 8080 on some machines.

Failed to fetch on every API

The HttpListener is not running. Run start.bat again and open http://localhost:8787/api/v1/health. Use .\tools\smoke-api.ps1 to verify.

If you set bindHost to a single LAN IP only, older builds broke the localhost UI (launcher opens localhost). Use bindHost: 0.0.0.0 and accept UAC. v2.1.4+ also keeps a localhost listener when binding a concrete IP.

Server fails to start

  • Run api\server.ps1 directly to see errors.
  • Check logs\yyyy-MM-dd.log.
  • Ensure you launch via start.bat (handles paths with spaces).

Actions return Access Denied

Approve the UAC prompt from start.bat. Confirm the header badge shows ELEVATED.

Tools: Invoke-ToolCommand not recognized

Restart the server after updating. Module libs must load before each action (fixed in 1.2).

SyncMe not found

If SyncMe is running on this PC it can auto-register with LocalOps. Otherwise run OpenDownloadPage to open syncme.co.za, install SyncMe, then set syncMePath in settings.json if needed and restart.

Remote open files / sessions fail

Need elevation and SMB admin rights on the target PC. Registry reads require Remote Registry enabled on the target.

If ListShares, ListOpenFiles, or ListSessions times out, verify target firewall rules and RPC/WMI/SMB reachability, then retry.

Update check fails

  • Verify updateUrl is reachable from the PC (browser test).
  • Confirm JSON is valid and builds[].url resolves.
  • If SHA-256 is set, it must match the ZIP or apply will abort.

Remote agent cannot enroll

  • -ServerUrl must be the console’s LAN IP or fleetPublicUrl, not 127.0.0.1.
  • Set console bindHost to 0.0.0.0 (not a single LAN IP) and set fleetPublicUrl; restart; allow firewall TCP on the port.
  • If the server fails with “conflicts with an existing registration”, stop leftover listeners on 8787 and run netsh http show urlacl.
  • See Installation. LocalOps Agent.

Module missing

Ensure modules/*/module.json is valid JSON. Health reports module load errors.

UI looks unstyled

Assets are local under dashboard/assets. If you only opened index.html from disk without the server, API calls will fail. Always use the HttpListener URL.
