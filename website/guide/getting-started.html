Getting started

LocalOpsConsole is free and open source (MIT). Grab a release, run the bootstrap script, or clone from GitHub.

Install

  1. Download LocalOpsConsole-x.y.z.zip from GitHub Releases or the Download page.
  2. Extract to a writable folder (example: C:\Tools\LocalOpsConsole).
  3. Double-click start.bat (do not double-click start.ps1 — Windows may open it in Notepad).
  4. On this PC, open http://localhost:8787/ (the launcher usually opens it for you).

Or use the bootstrap script to download and extract under %LOCALAPPDATA%\LocalOpsConsole.

Full docs: Installation (includes LocalOps Agent on other PCs).

Launch

start.bat

The launcher requests UAC elevation by default so remediations work. Standard users can still run most diagnostics without elevation.

localhost / 127.0.0.1 is only for browsing the dashboard on the console host. Other PCs must use this machine’s LAN IP (see below).

UI tour

  • Header — product name, version, elevation badge, telemetry chips (CPU/RAM/DISK/NET/GPU/VPN), Shutdown button.
  • Profile selector — choose operator profile; this only changes which modules are shown in the sidebar.
  • Sidebar — modules from GET /api/v1/modules.
  • Main pane — module view; results render as tables/cards when data is tabular.
  • Live console — docked stream of INFO / SUCCESS / WARN / ERROR lines.

settings.json

{
  "port": 8787,
  "cacheTtlSeconds": 20,
  "taskIntervalSeconds": 30,
  "logRetentionDays": 14,
  "bindHost": "localhost",
  "fleetPublicUrl": "",
  "updateUrl": "https://www.opsconsole.co.za/uploads/update.json",
  "syncMePath": "",
  "rustDeskInstallerUrl": "",
  "rustDeskInstallerSha256": "",
  "rustDeskSilentArgs": ""
}

Change port if 8787 is busy. Default updateUrl is https://www.opsconsole.co.za/uploads/update.json — leave blank to skip update checks (see Updates). Set syncMePath only if SyncMe is installed locally. Set rustDeskInstallerUrl for Remote Support silent install.

  • bindHost — default localhost (this PC only). Set 0.0.0.0 or your LAN IP when remote agents or other browsers must reach the API.
  • fleetPublicUrl — optional, e.g. http://192.168.1.10:8787, to pin the Computers install one-liner.

LocalOps Agent on another PC

  1. On the console PC set bindHost to 0.0.0.0 (and optionally fleetPublicUrl to http://<this-PC-LAN-IP>:8787), then restart.
  2. Open Computers, copy the install command. -ServerUrl should be the LAN IP or fleetPublicUrl — not 127.0.0.1.
  3. On the remote PC, extract LocalOpsAgent-x.y.z.zip and run that command as Administrator.
powershell -ExecutionPolicy Bypass -File .\Install-LocalOpsAgent.ps1 -ServerUrl "http://192.168.1.10:8787" -EnrollToken "YOUR_TOKEN"
Elevation badge: STANDARD USER can navigate and run most diagnostics. Remediations show Needs elevation until you approve UAC from start.bat, or right-click → Run as administrator.
