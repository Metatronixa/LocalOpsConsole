Getting started

LocalOpsConsole is free and open source (MIT). Grab a release, run the bootstrap script, or clone from GitHub.

Install

  1. Download LocalOpsConsole-x.y.z.zip from GitHub Releases or the Download page.
  2. Extract to a writable folder (example: C:\Tools\LocalOpsConsole).

Or use the bootstrap script to download and extract under %LOCALAPPDATA%\LocalOpsConsole.

Launch

Double-click start.bat (do not double-click start.ps1 — Windows may open it in Notepad instead of running it).

start.bat

The launcher requests UAC elevation by default so remediations work. It starts the API and opens http://localhost:8787/. Standard users can still run most diagnostics without elevation.

UI tour

  • Header — product name, version chip, elevation badge, CPU/RAM strip.
  • Profile selector — choose operator profile; this only changes which modules are shown in the sidebar.
  • Sidebar — modules from GET /api/v1/modules.
  • Main pane — module view; results render as tables/cards when data is tabular.
  • Live console — docked stream of INFO / SUCCESS / WARN / ERROR lines.

settings.json

{
  "port": 8787,
  "cacheTtlSeconds": 20,
  "taskIntervalSeconds": 30,
  "logRetentionDays": 14,
  "bindHost": "localhost",
  "updateUrl": "https://raw.githubusercontent.com/Metatronixa/LocalOpsConsole/main/website/uploads/update.json",
  "syncMePath": ""
}

Change port if 8787 is busy. Leave updateUrl blank to skip update checks, or point it at the GitHub manifest / your own host (see Updates). Set syncMePath only if SyncMe is installed locally.

Elevation badge: STANDARD USER means remediations may be blocked. Approve the UAC prompt from start.bat, or right-click → Run as administrator.
