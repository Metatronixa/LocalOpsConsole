Modules

Every module folder contains module.json, diagnostics/, actions/, and optional lib/.

Graphics

  1. Run GetAdapters for GPU name, driver version, and driver date.
  2. Run OpenVendorUpdatePage to open NVIDIA, AMD, or Intel driver download pages.

Remote

  1. DiscoverComputers — neighbors from ARP / SMB connections; click a PC to select it.
  2. ListShares — SMB shares on the selected target (fast-fail if unreachable; bounded timeouts).
  3. ListOpenFiles / ListSessions — need admin + rights on the target.
  4. GetRemoteRegistry — read-only remote registry; EnsureRemoteRegistry can start the local Remote Registry service.
  5. If remote SMB/CIM calls time out, verify target firewall/RPC/WMI/SMB access, then retry.

SyncMe

  1. Install SyncMe from syncme.co.za if it is not already present.
  2. Set syncMePath in settings.json when your install location is custom.
  3. GetStatus validates install path and local console listener state.
  4. OpenConsole launches the SyncMe web UI.
  5. StartBackup starts the backup script in the background.
  6. OpenDownloadPage opens the SyncMe setup package directly when SyncMe is missing.

Printers

  1. Open Printers — select a printer for detail (driver, port, jobs).
  2. Use the spooler panel for status; elevate for Restart / Kill process / Set Automatic.
  3. Queue table: Cancel / Pause / Resume jobs; Clear all when elevated.
  4. Run a TCP/IP network test (Ping, DNS, ports 9100/515) on network printers.
  5. Review recent print/spooler event errors in the events panel.

Remote Support (RustDesk)

  1. Open Remote Support under Enterprise — status, version, service, and ID (passwords are never shown).
  2. Copy ID for the technician; Open / Start / Stop / Restart as needed (service actions need elevation).
  3. Set rustDeskInstallerUrl in settings.json to enable silent Install (optional SHA-256).

VPN

  1. When connected, the header shows a VPN chip (name truncated; details in tooltip).
  2. Run GetConnections for RAS profiles and tunnel adapters.
  3. Run Diagnose for gateway reachability and DNS hints.
  4. If a stale WAN miniport is suspected, elevate and run ResetWanMiniport.

Internet Health

  1. Open Internet Health under Networking (replaces separate Network / VPN / Troubleshooter menu items).
  2. Summary loads automatically — gateway, DNS, public reachability, overall health %.
  3. Run individual connectivity tests, edit hosts (elevated), manage VPN, or click Run diagnosis for recommended repairs.
  4. Speed test is optional and never runs on page load.

Network

  • GetStatus — adapters, IPv4, gateway, DNS, WINS, NetBIOS mode, link speed.
  • Hosts file — view entries; Add / Remove / Toggle require elevation (backup hosts.bak.loc).
  • GetWins / GetNbstat — WINS servers and NetBIOS name table/cache.
  • Ping — ICMP to a target (default 8.8.8.8).
  • FlushDNS / RenewIP — admin remediations.

Shutdown

Use the header Shutdown button to stop the LocalOpsConsole server; the launcher window closes when the process exits.

Tools

Classic IT readouts: IpConfig, Netstat, RoutePrint, Arp, Nslookup, Whoami, Hostname, SystemInfo, PowerCfg, DismGetHealth, SfcVerifyOnly, ChkdskStatus, GpResult. Action: GpUpdate.

  • Nslookup — set Host / IP in the Tools panel, then run Nslookup.
  • RouteAdd (admin) — Destination + Gateway + Mask; optional Permanent checkbox.
  • A spinner shows while any tool is running.

OS repair (admin, long-running): SfcScanNow (sfc /scannow) and DismRestoreHealth.

Configuration

  1. Open Configuration to browse documented Windows settings by category: Explorer, Privacy, Windows Update, Taskbar, Power, Security.
  2. Each card shows current, recommended, Microsoft default, risk, restart needs, and registry/provider path.
  3. Use Apply recommended or Restore default (with confirmation). Some settings require elevation; Insider status is read-only.

Windows Update module

GetPending lists pending updates when the COM API is available. ResetComponents restarts WU-related services. ClearSoftwareDistribution renames cache folders — use only when WU is corrupted.

System

Live monitor for CPU and RAM (sparklines), network up/down bandwidth, disk I/O read/write MB/s + IOPS, all fixed disks (accordion — one open at a time), GPU identity, battery (if present), problem devices, uptime, and pending reboot. The header strip mirrors key metrics and bandwidth rates. Refresh forces a new telemetry snapshot.

Other modules

  • Storage — volumes, SMART, clear temp.
  • Services — search and start/stop/restart.
  • Security — firewall profiles, Defender status, quick scan.
  • Event Log — recent Critical/Error events.
  • Devices / Power / Users / Audio / Startup — see in-app Diagnostics and Actions lists.
