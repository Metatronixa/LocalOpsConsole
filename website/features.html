Features

Free and open source (MIT). Core engine plus the module set in v1.2 — live telemetry, Configuration, Graphics, Remote, SyncMe, and OS repair.

Plugin modules

Discovered via module.json. Diagnostics and actions stay separated.

Readable results

Tables and cards for objects (printers, hosts, GPUs) — not raw JSON dumps.

Forced elevation

start.bat / start.ps1 request UAC so remediations work by default.

Offline UI

No CDN. Styling survives broken DNS/VPN.

Self-hosted updates

Check uploads/update.json, download ZIP, verify SHA-256.

Live console

Every step streams to the sticky execution log and daily log files.
