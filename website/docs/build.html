Build & release

  1. Bump SemVer in VERSION (and notes in CHANGELOG.md).
  2. Run .\build.ps1, stamps version, stages package, generates integrity hashes, sets packaged integrityMode: enforce, writes dist/LocalOpsConsole-x.y.z.zip and dist/LocalOpsAgent-x.y.z.zip.
  3. Optional: .\build.ps1 -PublishWebsite, copies ZIP under website/uploads/builds/ and refreshes update.json.
  4. Publish a GitHub Release with both ZIPs; set builds[].url to the Release asset (or a mirror under https://www.opsconsole.co.za/uploads/builds/).
  5. Deploy website/uploads/update.json to https://www.opsconsole.co.za/uploads/update.json (default in-app check URL).
  6. Tag and publish a GitHub Release with both ZIPs.
