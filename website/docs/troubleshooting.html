Troubleshooting

  • Check daily logs under logs/.
  • Confirm elevation badge for remediations.
  • Use Live Console stream for action errors.
  • Verify module scripts are listed in module.json.
  • If the UI is blank, hard-refresh the browser (Ctrl+F5).

Remote agent cannot enroll / connect

  • Confirm -ServerUrl is the console PC’s LAN IP (or fleetPublicUrl), not 127.0.0.1 / localhost.
  • On the console, set bindHost to 0.0.0.0 (or the LAN IP) and restart — default localhost rejects remote clients.
  • Allow inbound TCP on the console port (default 8787) in Windows Firewall.
  • From the remote PC, test in a browser: http://<console-LAN-IP>:8787/.
