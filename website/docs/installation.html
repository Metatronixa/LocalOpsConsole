Installation

Console (this PC)

  1. Download the latest LocalOpsConsole-x.y.z.zip from GitHub Releases.
  2. Extract to a writable folder (example: C:\Tools\LocalOpsConsole).
  3. Run start.bat (UAC elevation recommended for remediations).
  4. Open the printed URL in your browser — on the console host that is normally http://localhost:8787/.

Or clone the repository and run start.bat / start.ps1 from source.

localhost / 127.0.0.1 is correct when you browse the dashboard on the same PC that runs the API.

Settings that matter for install

Edit settings.json next to the app:

  • port — default 8787
  • bindHost — default localhost (this PC only). Use 0.0.0.0 or your LAN IP when other PCs must reach the API.
  • fleetPublicUrl — optional pin for the Computers install one-liner (e.g. http://192.168.1.10:8787)
  • updateUrl — default https://www.opsconsole.co.za/uploads/update.json; Event Intelligence prefs; integrityMode (warn vs enforce)

LocalOps Agent (other PCs)

Fleet is optional. Agents phone home outbound — no listener on managed desktops. From another PC you must use a reachable console URL, not 127.0.0.1.

1. Open the console to the network

On the console PC, set in settings.json and restart:

{
  "bindHost": "0.0.0.0",
  "port": 8787,
  "fleetPublicUrl": "http://192.168.1.10:8787"
}

Replace 192.168.1.10 with this PC’s LAN IPv4. Allow inbound TCP on the chosen port in Windows Firewall if prompted.

2. Copy the install command

  1. Open Computers (Operations → Fleet).
  2. Copy the enrollment token and install one-liner.

The suggested -ServerUrl prefers fleetPublicUrl, otherwise the detected LAN IP (never loopback when a LAN address is available). Example:

powershell -ExecutionPolicy Bypass -File .\Install-LocalOpsAgent.ps1 -ServerUrl "http://192.168.1.10:8787" -EnrollToken "YOUR_TOKEN"

3. Install on the remote PC

  1. Copy LocalOpsAgent-x.y.z.zip (or the agent folder) to the target PC.
  2. Extract and run the one-liner as Administrator.
  3. Confirm the agent appears under Computers on the console.

URL cheat sheet

  • Browser on console PC → http://localhost:8787/ is fine
  • Agent / browser from another PC → http://<console-LAN-IP>:8787/ (or your fleetPublicUrl)
  • Wrong → http://127.0.0.1:8787/ on a remote PC (points at that remote PC, not the console)
