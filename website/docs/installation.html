Installation

From ZIP / GitHub Release

  1. Download the latest LocalOpsConsole-x.y.z.zip.
  2. Extract to a folder you can write to.
  3. Run start.bat (UAC elevation recommended for remediations).
  4. Open the printed URL in your browser.

From source

Clone the repository and run start.bat or start.ps1.

Settings

Edit settings.json for port, bind host, Event Intelligence prefs, and integrity mode (warn vs enforce).
