FAQ

Port already in use?

Change port in settings.json or stop the other listener.

Why not 127.0.0.1 for agents?

On another PC, 127.0.0.1 means that PC — not the console. Use the console’s LAN IP (or fleetPublicUrl) and set bindHost to 0.0.0.0. See Installation.

Integrity failures in development?

Set integrityMode to warn (default for source) or regenerate hashes.

Event Intelligence empty?

Ensure eventIntelEnabled is true and wait for watchers/health ticks; Overview should still load scores.
