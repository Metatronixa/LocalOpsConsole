FAQ

Port already in use?

Change port in settings.json or stop the other listener. Default is 8787.

Why “Failed to fetch” on every API?

The HttpListener process is not running. Restart with start.bat and confirm http://localhost:8787/api/v1/health returns JSON. This is not a per-module bug.

Why not 127.0.0.1 for agents?

On another PC, 127.0.0.1 means that PC, not the console. Use the console’s LAN IP (or fleetPublicUrl) and set bindHost to 0.0.0.0. See Installation.

Settings page showed HTTP 405?

Fixed in v2.1.1. Upgrade or pull latest; GET/POST /api/v1/settings must work. Other methods correctly return 405.

Graphics / Startup / Devices pages blank?

Fixed in v2.1.1 (PowerShell single-item array JSON). Hard-refresh the UI after updating. Inventory section is open by default.

Integrity failures in development?

Set integrityMode to warn (default for source) or regenerate hashes with build.ps1.

Event Intelligence empty?

Ensure eventIntelEnabled is true and wait for watchers/health ticks; Overview should still load scores.

PowerShell 4104 in Timeline?

Windows Script Block Logging often records api\server.ps1 when the console starts. Event Intel surfaces those events. They are not by themselves a crash.
