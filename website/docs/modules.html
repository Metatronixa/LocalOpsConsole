Modules

Each folder under modules/ has module.json, optional diagnostics/, actions/, and lib/. Profiles filter which modules appear in the sidebar.

Layout in the UI

  • Overview, Overview
  • Operations, Computers (Fleet), Tools, Configuration, Internet Health, Network, Remote, Services, Printers, Updates, Audio, SyncMe, Remote Support, VPN, …
  • Security, Security Center, Security Baseline, Security Tools, Event Log
  • Health / Performance / Inventory, Health Center, System, Devices, Users, Graphics, Storage, Startup, Power
  • Incidents / Monitoring / Automation / Settings, Incident Center, Alerts, Timeline, Automation, Settings

Capabilities

Manifests may declare capabilities: inventory, diagnostics, monitoring, remediation, automation, reporting, analytics.

Views

Rich custom JS views exist for Overview, System, Services, Network, Storage, Fleet, Security*, Incidents, Alerts, Timeline, Automation, Settings, Internet Health, and others. Remaining modules use the generic ModuleView (diagnostics + remediation buttons). The UI normalizes single-item arrays from PowerShell JSON so those pages always render.
