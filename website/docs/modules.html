Modules

Each module folder contains module.json, optional diagnostics/, actions/, and lib/.

Documentation template

For every module, document: Purpose, Capabilities, Diagnostics, Remediation, Automation, Permissions, Security implications, Expected runtime, Typical use cases. See docs/modules/ in the repository for per-module pages.

Capabilities field

Manifests may declare capabilities such as inventory, diagnostics, monitoring, remediation, automation, reporting.
