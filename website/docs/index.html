Documentation

Professional reference for LocalOpsConsole v2.1.1 — the local-first Windows Operations Platform.

What you get

  • Offline SPA dashboard (Overview first)
  • PowerShell HttpListener API on localhost by default
  • Event Intelligence → Incidents → Notifications
  • Plugin modules with integrity / elevation / path jail
  • Optional LocalOps Agent fleet (LAN)

Quick start

Run start.bat, elevate if prompted, open the browser URL shown (default http://localhost:8787/ on the console PC). You land on Overview. For agents on other PCs, see Installation — use the console LAN IP, not 127.0.0.1.
