API

Base path: /api/v1/. JSON envelope: { Success, Message, Timestamp, Data }.

Business logic lives in core services, router.ps1 only dispatches. Methods other than those listed return 405.

Platform

  • GET health, version, elevation, module count
  • GET modules, manifests for the sidebar (arrays forced for diagnostics/actions)
  • GET telemetry, live CPU/RAM/disk/net snapshot (?force=1)
  • GET logs/tail?lines=n, console feed
  • GET|POST settings, read safe settings; POST updates Event Intel notification prefs
  • GET integrity/status, GET automation/status
  • GET updates/check, POST updates/apply
  • POST shutdown, stops HttpListener

Event Intelligence

  • GET incidents, GET incidents/{id}, POST …/ack, POST …/resolve
  • GET alerts, POST alerts/{id}/ack
  • GET timeline, GET events, GET rules
  • GET health-score, GET security-score, GET heatmap
  • GET|PUT|POST notifications/prefs
  • GET event-intel/status

Modules

  • GET {module}/diagnostics/{name}, optional query params
  • POST {module}/actions/{name}, JSON body params; admin-gated when listed in requiresAdmin

Fleet

  • GET fleet/enroll-token, POST fleet/enroll-token/rotate
  • POST fleet/enroll, token-based (no HMAC yet)
  • POST fleet/heartbeat, GET fleet/poll, POST fleet/results, POST fleet/events, HMAC after enroll
  • GET fleet/agents, GET fleet/agents/{id}, POST …/revoke
  • GET|POST fleet/commands, GET fleet/scripts
