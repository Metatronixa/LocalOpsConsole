Architecture

Browser SPA (dashboard/) ↔ HttpListener (api/server.ps1) ↔ thin router.ps1 ↔ core services ↔ plugin modules.

Core services

  • Engine.ps1 — ordered bootstrap
  • SecurityManager / IntegrityManager / PermissionManager — execution gate
  • EventEngine + Watch / Rule / Correlation / Incident / Notification / Automation
  • ModuleLoader — manifests, depends, invoke
  • TaskRunner — live telemetry

Event pipeline

Observe → Normalize → Rule Engine → Correlation → Incident → Notification → Timeline → Dashboard (Overview / Incidents).
