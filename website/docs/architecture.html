Architecture

LocalOpsConsole is a local-first Windows Operations Platform: an offline SPA dashboard talking to a PowerShell HttpListener API that loads plugin modules and optional Event Intelligence.

Runtime flow

  1. start.bat → start.ps1 (UAC elevation when possible).
  2. Launches api/server.ps1 with port, modules path, dashboard path, root.
  3. Server dot-sources core/Engine.ps1 file list at script scope (required for PowerShell scoping).
  4. HttpListener serves dashboard/ static files and routes /api/v1/* through api/router.ps1.
  5. Browser opens http://localhost:{port}/ (default 8787) on Overview.

Layers

  • Dashboard (dashboard/) — vanilla JS SPA: app.js sidebar/profiles, router.js views, custom module views + generic ModuleView.
  • API (api/) — thin router: health, modules, settings, telemetry, Event Intel, fleet, then {module}/diagnostics|actions/{name}.
  • Core (core/) — settings, security gate, modules, telemetry, Event Intelligence, fleet, updater, automation.
  • Modules (modules/*/module.json) — diagnostics & actions as PowerShell scripts.
  • Rules / notifications — Event Intel rules under rules/; channel plugins under notifications/.

Core bootstrap order

Engine.ps1 loads Response → Security → Settings → Logger → Cache → Integrity → Permission → ModuleLoader → SecurityManager → TaskRunner → Updater → Fleet* → EventStore → Timeline → Severity → Rule → Correlation → Incident → Notification → Watch → Health → SecurityScore → Automation → EventEngine.

Execution gate

Every module diagnostic/action passes SecurityManager:

  1. Manifest validation
  2. SHA-256 integrity (warn in source; enforce in packaged builds)
  3. Elevation / requiresAdmin
  4. Dependencies
  5. Parameter allow-list
  6. Path jail (script must stay under the module folder)

Event Intelligence pipeline

When eventIntelEnabled is true:

Watch (Event Logs + signals) → Normalize → RuleEngine (rules/) → Correlation → Incident → Notify (channels, quiet hours) → Timeline → Dashboard (Overview / Incidents / Alerts).

Automation playbooks run only when a rule sets automation.enabled: true (opt-in, audited).

Fleet (optional)

Outbound LocalOps Agent enrolls with a token, then heartbeats and polls commands with HMAC. Console default bind is localhost — remote agents need bindHost: 0.0.0.0 (or LAN IP) plus a reachable ServerUrl / fleetPublicUrl. See Installation.

Data on disk

  • data/events/, data/incidents/ — Event Intel persistence
  • data/fleet/ — agents, commands, audit
  • data/integrity/ — module hashes (packaged builds)
  • logs/ — daily operational logs
