Bootstrap script

Give this to a colleague — downloads the latest release, verifies SHA-256 when present, extracts under %LOCALAPPDATA%\LocalOpsConsole.

iwr https://raw.githubusercontent.com/Metatronixa/LocalOpsConsole/main/website/uploads/Install-LocalOpsConsole.ps1 -OutFile "$env:TEMP\Install-LOC.ps1"
powershell -ExecutionPolicy Bypass -File "$env:TEMP\Install-LOC.ps1" -Launch

Install-LocalOpsConsole.ps1 · update.json

Install

  1. Extract the ZIP to a folder you can write to (e.g. C:\Tools\LocalOpsConsole).
  2. Right-click start.bat → Run as administrator (recommended), or double-click it. Do not open start.ps1 with Notepad.
  3. Open http://localhost:8787/ (default port in settings.json).
Elevation: Standard users can navigate and run most diagnostics. Remediations need Administrator.

Publish your own updates

Copy a new build into website/uploads/builds/, update website/uploads/update.json, and set the app’s updateUrl to that JSON. Or point at GitHub Releases assets.

{
  "latest": "2.0.0",
  "builds": [{ "version": "2.0.0", "url": "uploads/builds/LocalOpsConsole-2.0.0.zip", "sha256": "..." }]
}
