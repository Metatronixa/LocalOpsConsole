System requirements

  • Windows 10 or 11
  • PowerShell 5.1+
  • Modern browser for the dashboard
  • Administrator elevation for remediations

Install

# Console on this PC
start.bat
# Browser: http://localhost:8787/

# Agent on another PC. Use console LAN IP, not 127.0.0.1
# 1) Console settings.json: "bindHost": "0.0.0.0"
# 2) Computers → copy install command
# 3) On remote PC (Admin):
.\Install-LocalOpsAgent.ps1 -ServerUrl "http://192.168.1.10:8787" -EnrollToken "TOKEN"
